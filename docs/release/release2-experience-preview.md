# Release 2 experience concept

Prepared 9 November 2026. The desktop and mobile image boards generated in this chat are **proposed future designs**, with fictional companies, numbers, dates, source labels and usage. They are not deployed screens or verified financial data.

The proposed flow is Daily Review → selected holding/company research → evidence, calendar and alert explanation. Keep daily priorities and next checks first; place advanced analysis behind focused sections/disclosures. Mobile uses large touch targets and a short task navigation bar. Company research separates supporting/adverse facts, periods, sources and explicit unavailable metrics. Validation keeps experimental and pending outcomes visible.

Final implementation must preserve the existing contracts: metadata is not source truth; provider limits/counters are scoped and measured; Telegram acceptance is not account delivery or a read receipt; financial outputs require supported accounting and source inputs. The refined desktop concept uses provider acceptance and ledger reconciliation labels rather than claiming delivered/read status. Exact limits, disclosures and source semantics follow tested contracts, not generated mockup text.

Image files remain outside Git under `/workspace/generated_images`. No application dependency, deployment or production redesign is activated by a concept image. The company dossier, broader enrichment/evaluation and some displayed integrations remain pending in the [release plan](release2-engineering-plan.md).

Ask the Analyst

A question box wired to the local agent backend. Supervisor mode routes to market/filings specialists; Autonomous mode discovers the MCP tools at runtime and builds an evidence chain across market, SEC filings, milestones, earnings, and rotation. This runs against the Python service — not Finnhub — so it needs the backend running.

i
This talks to your own agent backend (app.main:app), not a hosted API. Start it with uvicorn app.main:app --reload and set its URL in Settings if it isn't at http://localhost:8000. In stub mode the answers are deterministic, grounded placeholders — the point is the routing, not the prose.

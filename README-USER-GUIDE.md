# AI Infra Watch - Functional User Guide

Welcome to **AI Infra Watch**, a premier tactical intelligence platform tracking the physical assets, raw power grids, supply chain lanes, and geopolitical actions driving the global artificial intelligence expansion.

---

## 1. What is AI Infra Watch?

While most of the world focuses on the software layer of generative AI (such as LLMs and chatbots), **AI Infra Watch** focuses on the **physical layer**: the massive datacenters, utility power requirements, silicon shipping routes, and insider transactions that make AI possible.

This application acts as a telemetry command dashboard for supply chain analysts, researchers, and infrastructure investors. It consolidates real-time geopolitical intelligence and maps physical assets against market trends.

---

## 2. Core Operational Modules

The dashboard is structured into four primary command tiles:

### 📡 Module A: Real-Time Stock Telemetry (The Blackwell & Energy Index)
Tracks high-impact equities that form the bedrock of AI computing, categorized into three distinct buckets:
- **Silicon Leaders**: Hardware suppliers like **Nvidia (NVDA)**, **AMD (AMD)**, and **Micron (MU)**.
- **Hyperscale Hosts & Power Providers**: Specialized infrastructure companies like **NBIS** (dedicated AI cluster leasing) and **DGXX** (regional grid power and datacenter hosting).
- **Core Technology**: Compute layers such as **Cerebras (CERE)** and server software fabrics.

### 💼 Module B: Datacenter & Power Infrastructure Leases
Displays multi-billion-dollar long-term hosting and energy contracts. Here you can track:
- Which hyperscalers (e.g., Meta, Microsoft) are leasing physical cluster nodes.
- Detailed specifications of hardware (e.g., NVIDIA Blackwell clusters vs. custom wafer colocation builds).
- Asset locations (such as the 40MW campus in Columbiana, Alabama, or the Vineland, New Jersey Azure node).
- **AI Impact Syntheses**: Bullet-proof analysis summarizing exactly why these contracts matter in the long run.

### 🏛️ Module C: Congressional Insider Trade Monitor
Exposes stock trades made by members of the Senate and House of Representatives on technology and energy stocks. 
- Aligns transaction timelines with policy decisions (like the CHIPS Act or local utility permissions).
- Highlights details of target ticker symbols, transaction types (Buy vs. Sell), and disclosure filing ranges.

### 🌋 Module D: Geopolitical & Macro Risk Registry
A tactical vulnerability list mapping high-alert hazards that could disrupt the AI physical pipeline:
- **Taiwan Strait Shipping Lane Control**: Geopolitical supply disruptions affecting TSMC semiconductor fabricators.
- **Regulatory GPU Power Ceilings**: Local environmental caps preventing datacenter grid expansion over 100MW.
- **Silicon Embargoes**: Expanded export bans narrowing foreign hardware monetization pathways.

## 3. How to Use & Interpret the Dashboard

### 🔄 Performing a Live Feed Update
To query the raw, real-time geopolitical feeds, click the **"Refresh Live Feed"** button in the dashboard header. This action bypasses cached files and commands the backend server to aggregate global articles and synthesize them via Gemini AI.

### 🟢 Interpreting Connectivity & API Statuses
The upper right-hand corner of the dashboard displays a diagnostic signal line. It indicates how your current feed is being served:
- **"Active Synthesis"**: The dashboard is powered by real-time Gemini AI processing current global news articles.
- **"Cached Feed (5m)"**: The server is serving a secure, high-speed cached state from the last 5 minutes to maintain performance.
- **"Pre-Synthesized Offline Feed"**: If the Gemini API is in a 30-minute rate-limit cooldown, or if the server's API key is unconfigured, the application gracefully falls back to this mode. You will still receive beautiful, high-fidelity, hand-curated analytics and mock data without seeing broken loading tiles or application errors.

### 🔍 Filtering Data Streams
Click on any ticker symbol in the Stock Telemetry table to immediately highlight related contracts or congressional trades. This cross-filtering feature allows you to map political insider trades directly against real-world datacenter contracts!
